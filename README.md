Dataset Name: Customer Churn Prediction Dataset

Dataset Description:
This dataset contains customer information from a telecom service provider, including demographic data, account details, services subscribed to, billing information, and whether the customer churned or not. It has 300 records and 21 columns. Features include tenure, contract type, payment method, monthly charges, total charges, and service options.

Machine Learning Problem Type:
This is a Classification problem.

Target Variable:
Churn (Yes/No)

Problem Statement:
The goal of this machine learning problem is to build a classification model that predicts whether a customer will churn based on their demographic information, subscribed services, contract type, and billing features. The model will learn patterns that distinguish customers who leave the service from those who stay.
